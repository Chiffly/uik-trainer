# Практикум УИК

Учебная игра: 10 посетителей, документы на столе, диалоги и разбор решений в конце смены.

Все персонажи, адреса и документы вымышлены. Это авторский прототип, не официальный продукт ЦИК и не аттестация. Прогресс хранится только в браузере игрока; общего сбора результатов нет.

Статический сайт без сборки и внешних runtime-зависимостей. GitHub Pages: ветка main, папка /(root). Для локального просмотра откройте index.html.

Иллюстрации созданы с помощью ИИ для этого проекта. Шрифт Inter распространяется по SIL Open Font License, текст — assets/OFL.txt.
